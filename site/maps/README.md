# Map geometry

`china.json` was retrieved on 2026-11-15 from Alibaba Cloud DataV's administrative boundary service:
https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json

It is bundled locally to avoid external map requests when viewing the static demo. Geometry is used for provincial summaries; it is not a road map and province centroids are never presented as exact charging station locations.
